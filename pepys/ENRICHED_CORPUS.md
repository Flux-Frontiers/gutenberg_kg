# Pepys Enriched Corpus

Produces a topic-classified, pipe-delimited text file from the full Pepys corpus for use in embedding experiments (e.g. `../proteusPy/pepys`).

---

## Background

The pipeline stores pre-chunked entries in `pepys_clean_chunks.pkl` (Phase 1 output — 3,355 entries, ~6,700 chunks). This cache contains raw text chunks **without topic labels**. Topic classification (Phase 3 — hybrid supervised + k-means) runs separately during `DiaryTransformer.transform_file()`, but that method only processes a sampled batch (default: 20 entries).

`enrich_full_corpus.py` bridges the gap: it loads the full pkl, runs Phase 3 on every chunk, and writes the enriched output for downstream analysis.

---

## Files

| File | Description |
|------|-------------|
| `pepys_clean_chunks.pkl` | Pre-chunked entry cache (3,355 entries, no topic labels) |
| `enrich_full_corpus.py` | Script to classify all chunks and write enriched output |
| `pepys_enriched_full.txt` | Output — full corpus with topics (generated by script) |

---

## Output Format

Pipe-delimited, one chunk per line:

```
TIMESTAMP | semantic_category | context_classification | content
```

Example:
```
1660-04-01T12:00 | pepys_naval    | Office | Mr. Ibbott preached very well. After dinner my Lord did give me a private list of all the ships...
1660-04-01T12:00 | pepys_domestic | Social | At night the Captain, Sir R. Stayner, Mr. Sheply, and I did sup together in the Captain's cabin.
1660-04-02T16:34 | pepys_court    | Court  | He tells me that the King will come in, and that Monk did resolve to have the doing of it himself.
```

Source entry provenance is preserved as comments:
```
# === Source Entry #1 (1660-04-01 12:00) ===
# Original: raw | DiaryText
# Content: Mr. Ibbott preached very well...
# Extracted entries:
1660-04-01T12:00 | pepys_naval | Office | Mr. Ibbott preached very well...
```

## Usage

```bash
# Default — writes to pepys/pepys_enriched_full.txt
poetry run python pepys/enrich_full_corpus.py

# Custom output path
poetry run python pepys/enrich_full_corpus.py --output path/to/output.txt

# Tune chunking and seed
poetry run python pepys/enrich_full_corpus.py --max-chunks 2 --seed 123
```

**Options:**

| Flag | Default | Description |
|------|---------|-------------|
| `--pkl` | `pepys/pepys_clean_chunks.pkl` | Source chunk cache |
| `--output` | `pepys/pepys_enriched_full.txt` | Output file path |
| `--max-chunks` | `3` | Max chunks retained per entry |
| `--seed` | `42` | Random seed for k-means category discovery |

---

## What the Script Does

1. **Load pkl** — deserialises all 3,355 `DiaryEntry` objects with pre-computed chunks
2. **Collect chunk texts** — flattens entries into a single list of ~6,700 chunk strings
3. **Discover categories** — runs `discover_semantic_categories()` once over all chunks (k-means fallback seed)
4. **Classify** — for each chunk, calls `classify_chunk_hybrid()` (supervised first, k-means fallback) and `extract_context()`
5. **Build `EntryChunk` objects** — attaches `semantic_category`, `context_classification`, source provenance
6. **Sort chronologically** — by `timestamp`
7. **Save** — calls `save_entries()` with run-parameter header and source comments

Re-chunking is **skipped** — the pkl's pre-computed chunks are used directly, making this significantly faster than a full `transform_file()` run.

---

## Topic Categories

The supervised classifier uses `pepys_topics.yaml`. Representative categories:

| Category | Signals |
|----------|---------|
| `pepys_naval` | office, navy, ships, shipyard, board |
| `pepys_court` | his majesty, king, duke of york, whitehall |
| `pepys_domestic` | home, wife, servants, household |
| `pepys_social` | dinner, friends, tavern, music |
| `pepys_financial` | money, paid, accounts, salary |
| `pepys_health` | sick, pain, doctor, physic |

85% of chunks are classified by the supervised path; 15% fall back to k-means.

## Using in Embedding Experiments

The output file is self-contained. In `proteusPy/pepys` or any embedder, parse with:

```python
entries = []
with open("pepys_enriched_full.txt") as f:
    for line in f:
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        parts = line.split(" | ", 3)
        if len(parts) == 4:
            timestamp, topic, context, content = parts
            entries.append({
                "timestamp": timestamp,
                "topic": topic.strip(),
                "context": context.strip(),
                "content": content.strip(),
            })
```

The `topic` and `context` fields are ready to use as labels, stratification keys, or conditioning inputs for embedding analysis.
