gutenberg_kg.build_corpus

build_corpus.py — Build a single consolidated DocKG over the whole Gutenberg corpus (or a chosen subset of genres), written to bundles/<name>/.dockg/.

This differs from gutenberg_kg.ingest, which builds one DocKG per book and federates them through the KGRAG registry. Here we walk corpus/ once and produce a single graph.sqlite + lancedb index — the artifact that gets baked into the standalone "fat image" (Pepys-style: pull, run, query directly).

Genre is recoverable for free at query time: with the walk rooted at corpus/, every node's file_path is <genre>/<book>/<file>.md, so the genre is just the first path segment — no schema change, no tagging pass.

Chunk strategies are applied per-genre group. Sacred texts (Bible KJV, Quran, Torah, etc.) use the verse chunker which honours chapter:verse numbering. All other genres default to semantic. Override via --strategy genre:strategy or the strategy_overrides field on BuildCorpusOptions.

DiaryKG indices (already built per-diary with temporal metadata) are not re-ingested through DocKG. Instead, each corpus/diaries/*/.diarykg/ index is copied verbatim into bundles/<name>/diaries/; the handler can register both the DocKG and the DiaryKG indices through KGRAG.

Output layout::

bundles/
  gutenberg-all/
    .dockg/
      graph.sqlite
      lancedb/
      catalog.json
    diaries/
      pepys-complete/.diarykg/
      evelyn-vol1/.diarykg/
      …

bundles/ is gitignored and already in [tool.dockg].exclude, so the consolidated index is never re-ingested by a stray repo-root dockg build.

  3build_corpus.py — Build a single *consolidated* DocKG over the whole Gutenberg
  4corpus (or a chosen subset of genres), written to ``bundles/<name>/.dockg/``.
  5
  6This differs from :mod:`gutenberg_kg.ingest`, which builds one DocKG *per book*
  7and federates them through the KGRAG registry. Here we walk ``corpus/`` once and
  8produce a single ``graph.sqlite`` + ``lancedb`` index — the artifact that gets
  9baked into the standalone "fat image" (Pepys-style: pull, run, query directly).
 10
 11Genre is recoverable for free at query time: with the walk rooted at ``corpus/``,
 12every node's ``file_path`` is ``<genre>/<book>/<file>.md``, so the genre is just
 13the first path segment — no schema change, no tagging pass.
 14

 16Torah, etc.) use the ``verse`` chunker which honours ``chapter:verse`` numbering.
 17All other genres default to ``semantic``.  Override via ``--strategy genre:strategy``
 18or the ``strategy_overrides`` field on :class:`BuildCorpusOptions`.
 19
 20DiaryKG indices (already built per-diary with temporal metadata) are **not**
 21re-ingested through DocKG.  Instead, each ``corpus/diaries/*/.diarykg/`` index
 22is copied verbatim into ``bundles/<name>/diaries/``; the handler can register
 23both the DocKG and the DiaryKG indices through KGRAG.
 24
 25Output layout::
 26
 27    bundles/
 28      gutenberg-all/
 29        .dockg/
 30          graph.sqlite
 31          lancedb/
 32          catalog.json
 33        diaries/
 34          pepys-complete/.diarykg/
 35          evelyn-vol1/.diarykg/
 36          …

 61REPO_ROOT = Path(__file__).resolve().parents[2]
 62CORPUS_ROOT = REPO_ROOT / "corpus"
 63BUNDLES_ROOT = REPO_ROOT / "bundles"
 64
 65# Corpus subdirectories that are not book-text genres and must never be folded
 66# into the consolidated index (author index pages, the DiaryKG-built diaries).
 67NON_GENRE_DIRS = {"authors", "diaries"}
 68
 69# Default cap on SIMILAR_TO out-edges per chunk, applied only when discovery is
 70# explicitly enabled (--similar). Cross-book, cross-author similarity is
 71# high-signal (the "Tolstoy vs Dostoevsky" edges), but the served handler is
 72# semantic-first and never traverses these edges, so consolidated builds default
 73# to NOT discovering them — recomputing ~800k edges only bloats the shipped
 74# graph.sqlite. The cap-8 SIMILAR_TO validation applies to DocKG.query()'s
 75# hop-expansion path (per-book CLI queries, viz3d arcs), not this bundle.
 76DEFAULT_SIMILAR_K = 8
 77
 78# Per-genre default chunk strategy.  Genres not listed here get "semantic".
 79# "verse" fires the VerseChunker which respects chapter:verse numbering and
 80# also auto-detects verse format (>10% of lines match ^\d+:\d+\s).
 81# sacred-texts is NOT listed here: only the KJV Bible uses N:M verse format,
 82# and it lives in ancient-classical. The other sacred texts are prose translations
 83# that auto-detection correctly leaves as "semantic".
 84GENRE_STRATEGY: dict[str, str] = {}

 92@dataclass
 93class BuildCorpusOptions:
 94    """Flags controlling a consolidated corpus build."""
 95
 96    output: str | None = None  # output bundle name; default derived from genres
 97    similar_k: int = DEFAULT_SIMILAR_K
 98    similar_max_degree: int = DEFAULT_SIMILAR_K  # hard per-node degree cap
 99    discover_similar: bool = False  # served handler never traverses SIMILAR_TO; opt-in only
100    n_workers: int = 4
101    embed_batch_size: int = 64
102    embed_device: str = "auto"  # auto|cpu|mps|cuda
103    wipe: bool = True
104    update: bool = False  # incremental: embed only new/changed nodes, upsert, prune
105    dry_run: bool = False
106    quiet: bool = False
107    diaries_only: bool = False  # skip phases 1-3; re-bundle diary indices only
108    # Per-genre chunk strategy overrides (merged on top of GENRE_STRATEGY).
109    # Keys are genre names; values are DocKG strategy strings: "semantic",
110    # "sentence_group", "fixed", or "verse".
111    strategy_overrides: dict[str, str] = field(default_factory=dict)

145def derive_output_name(genres: list[str], override: str | None) -> str:
146    """Return the bundle directory name for a genre selection.
147
148    :param genres: Selected genres (sorted by caller; full set == all genres).
149    :param override: Explicit ``--output`` name; wins if given.
150    :return: ``gutenberg-all`` for the full corpus, ``gutenberg-<genre>`` for a
151             single genre, else a hyphen-joined ``gutenberg-<g1>-<g2>…`` slug.
152    """
153    if override:
154        return override
155    if set(genres) == set(ALL_GENRES):
156        return "gutenberg-all"
157    if len(genres) == 1:
158        return f"gutenberg-{genres[0]}"
159    return "gutenberg-" + "-".join(genres)

162def derive_exclude(genres: list[str]) -> set[str]:
163    """Return the set of directory names to prune from the ``corpus/`` walk.
164
165    Excludes every genre *not* selected, the non-genre corpus dirs, and the
166    built-in DocKG ``SKIP_DIRS`` (``.git``, ``.dockg``, ``.venv``, …). Pruning
167    the unselected genres lets us keep the walk rooted at ``corpus/`` so node
168    ``file_path``s stay genre-prefixed regardless of the subset chosen.
169
170    :param genres: Selected genres.
171    :return: Directory names to exclude at every level of the walk.
172    """
173    from doc_kg.dockg import SKIP_DIRS
174
175    unselected = set(ALL_GENRES) - set(genres)
176    return unselected | NON_GENRE_DIRS | set(SKIP_DIRS)

179def build_catalog(genres: list[str], out_dir: Path) -> tuple[int, int]:
180    """Write a ``catalog.json`` sidecar mapping ``<genre>/<book>`` → book metadata.
181
182    Parses each selected book's ``reference.md`` for author, title, and Gutenberg
183    ID. The key matches the ``<genre>/<book>`` prefix of every node's
184    ``file_path``, so the handler can join author/title onto a hit at query time
185    — no node-schema change, and the file bakes into the image alongside the
186    index (it lives inside ``.dockg/``).
187
188    :param genres: Selected genres.
189    :param out_dir: The bundle's ``.dockg/`` directory (where the index lives).
190    :return: ``(books_catalogued, books_with_author)``.
191    """
192    from gutenberg_kg.authors import parse_reference
193
194    catalog: dict[str, dict] = {}
195    with_author = 0
196    for genre in genres:
197        for ref in sorted((CORPUS_ROOT / genre).glob("*/reference.md")):
198            meta = parse_reference(ref)
199            key = f"{genre}/{ref.parent.name}"  # matches file_path prefix
200            catalog[key] = {
201                "genre": genre,
202                "book": ref.parent.name,
203                "title": meta.get("title"),
204                "author": meta.get("author"),
205                "author_birth": meta.get("author_birth"),
206                "author_death": meta.get("author_death"),
207                "author_url": meta.get("author_url"),
208                "ebook_id": meta.get("ebook_id"),
209            }
210            if meta.get("author"):
211                with_author += 1
212
213    (out_dir / "catalog.json").write_text(
214        json.dumps(catalog, indent=2, ensure_ascii=False), encoding="utf-8"
215    )
216    return len(catalog), with_author

219def bundle_diaries(out_dir: Path) -> int:
220    """Copy existing ``.diarykg/`` indices from ``corpus/diaries/`` into the bundle.
221
222    DiaryKG indices carry temporal metadata (YAML timestamps, diary-specific
223    chunks) that DocKG's semantic pipeline cannot reproduce.  We copy them
224    verbatim so the handler can register both ``KGKind.GUTENBERG`` (the DocKG
225    index) and ``KGKind.DIARY`` (each DiaryKG) through KGRAG — without
226    re-ingesting the diaries.
227
228    Destination layout::
229
230        bundles/<name>/diaries/<diary-name>/.diarykg/
231
232    :param out_dir: The bundle's ``.dockg/`` directory (sibling of ``diaries/``).
233    :return: Number of diary indices copied.
234    """
235    import shutil
236
237    diaries_root = CORPUS_ROOT / "diaries"
238    if not diaries_root.exists():
239        return 0
240
241    bundle_diaries_dir = out_dir.parent / "diaries"
242    n = 0
243    for diary_dir in sorted(diaries_root.iterdir()):
244        if not diary_dir.is_dir() or diary_dir.name.startswith("."):
245            continue
246        diarykg_dir = diary_dir / ".diarykg"
247        if not diarykg_dir.exists():
248            continue
249        dest = bundle_diaries_dir / diary_dir.name / ".diarykg"
250        dest.parent.mkdir(parents=True, exist_ok=True)
251        if dest.exists() or dest.is_symlink():
252            shutil.rmtree(dest)
253        shutil.copytree(str(diarykg_dir), str(dest), symlinks=True)
254        n += 1
255    return n

258def ensure_diaries_built(dry_run: bool = False, quiet: bool = False) -> int:
259    """Reconstruct any unbuilt diary indices so :func:`bundle_diaries` finds them.
260
261    Runs the DiaryKG pipeline — ``chunk-diaries`` (``.md`` → ``.diary/``) then
262    ``build-diaries`` (``.diary/`` → ``.diarykg/``) — idempotently: diaries that
263    already have a ``.diary/`` and ``.diarykg/`` are skipped.  This makes
264    ``gutenkg build-corpus`` self-sufficient on a clean clone instead of relying
265    on the Makefile to sequence ``build-diaries`` first.
266
267    :param dry_run: Print the plan without executing.
268    :param quiet: Suppress per-stage DiaryKG build progress.
269    :return: 0 on success, 1 if chunking or building any diary failed.
270    """
271    from gutenberg_kg.build_diaries import BuildDiariesOptions, run_build_diaries
272    from gutenberg_kg.diary.chunk import ChunkDiariesOptions, run_chunk_diaries
273
274    rc = run_chunk_diaries([], ChunkDiariesOptions(force=False, dry_run=dry_run))
275    if rc != 0:
276        return rc
277    rc, _results = run_build_diaries(
278        [], BuildDiariesOptions(force=False, dry_run=dry_run, quiet=quiet)
279    )
280    return rc

289def fmt_duration(seconds: float) -> str:
290    """Human-readable duration string."""
291    if seconds < 60:
292        return f"{seconds:.1f}s"
293    m, s = divmod(int(seconds), 60)
294    if m < 60:
295        return f"{m}m {s:02d}s"
296    h, m = divmod(m, 60)
297    return f"{h}h {m:02d}m {s:02d}s"

305def run_build_corpus(genres: list[str], opts: BuildCorpusOptions) -> int:
306    """Build one consolidated DocKG over the selected genres.
307
308    Genres are grouped by their effective chunk strategy, then each group is
309    walked and parsed into the *same* ``graph.sqlite`` (first group wipes, the
310    rest append).  A single embedding pass and a single LanceDB index pass run
311    over the combined node table.  Finally, any DiaryKG indices found under
312    ``corpus/diaries/`` are copied verbatim into the bundle.
313
314    :param genres: Genre names to include (already validated; empty == all).
315    :param opts: Build option flags.
316    :return: 0 on success, 1 on failure.
317    """
318    genres = sorted(genres) if genres else list(ALL_GENRES)
319    name = derive_output_name(genres, opts.output)
320    out_dir = BUNDLES_ROOT / name / ".dockg"
321    sqlite_path = out_dir / "graph.sqlite"
322    lancedb_path = out_dir / "lancedb"
323
324    # Effective strategy: defaults merged with caller overrides.
325    effective_strategy: dict[str, str] = {**GENRE_STRATEGY, **opts.strategy_overrides}
326
327    # Group genres by chunk strategy.
328    strategy_groups: dict[str, list[str]] = defaultdict(list)
329    for genre in genres:
330        strategy = effective_strategy.get(genre, "semantic")
331        strategy_groups[strategy].append(genre)
332
333    n_books = sum(
334        1
335        for g in genres
336        for p in (CORPUS_ROOT / g).iterdir()
337        if (CORPUS_ROOT / g).is_dir() and p.is_dir() and not p.name.startswith(".")
338    )
339
340    print("=== gutenkg build-corpus ===")
341    print(f"  bundle        : {name}")
342    print(f"  output        : {out_dir}")
343    print(
344        f"  genres        : {len(genres)} ({'all' if set(genres) == set(ALL_GENRES) else ', '.join(genres)})"
345    )
346    print(f"  books         : ~{n_books}")
347    print(f"  similar_k     : {opts.similar_k if opts.discover_similar else 'disabled'}")
348    _mode = {
349        "cpu": f"parallel (CPU multiprocessing, {opts.n_workers} workers)",
350        "mps": "streaming (single-process; GPU can't be shared across workers)",
351        "cuda": "streaming (single-process; GPU can't be shared across workers)",
352    }.get(
353        opts.embed_device,
354        "auto → streaming MPS (single-process)"
355        if _mps_available()
356        else f"auto → parallel CPU ({opts.n_workers} workers)",
357    )
358    print(f"  embed mode    : {_mode}")
359    print(f"  embed batch   : {opts.embed_batch_size}")
360    print(f"  embed device  : {opts.embed_device}")
361    print()
362    print("  strategy groups:")
363    for strategy, sg_genres in sorted(strategy_groups.items()):
364        print(f"    {strategy:16s} : {', '.join(sorted(sg_genres))}")
365    print()
366
367    if opts.diaries_only:
368        print("[diaries-only] skipping phases 1-3; building + bundling diary indices …")
369        if ensure_diaries_built(dry_run=opts.dry_run, quiet=opts.quiet) != 0:
370            print("[x] diary build failed")
371            return 1
372        try:
373            n_diaries = bundle_diaries(out_dir)
374        except Exception as exc:  # noqa: BLE001
375            print(f"[x] bundle_diaries failed: {exc}")
376            return 1
377        if n_diaries:
378            print(f"  copied {n_diaries} diary index(es) → bundles/{name}/diaries/")
379        else:
380            print("  (no .diarykg indices found under corpus/diaries/)")
381        return 0
382
383    if opts.dry_run:
384        print("[dry-run] phase 1: build graph — sequential per strategy group:")
385        for strategy, sg_genres in sorted(strategy_groups.items()):
386            sg_exclude = derive_exclude(sg_genres)
387            print(f"  strategy={strategy}, genres={sorted(sg_genres)}")
388            print(f"    exclude={sorted(sg_exclude)}")
389        print(f"[dry-run] phase 2: embed all nodes → {sqlite_path}")
390        print(f"[dry-run] phase 3: sqlite-vec index + SIMILAR_TO → {out_dir / 'vectors.sqlite'}")
391        print("[dry-run] phase 4: build (if needed) + bundle DiaryKG indices → bundles dir")
392        print(f"[dry-run] would write {out_dir / 'catalog.json'} (author/title per book)")
393        return 0
394
395    try:
396        from doc_kg.index import make_embedder
397        from doc_kg.kg import DocKG
398    except ImportError as exc:
399        print(f"[x] doc_kg not installed (needed for build-corpus): {exc}")
400        return 1
401
402    out_dir.mkdir(parents=True, exist_ok=True)
403
404    t0 = time.perf_counter()
405    # Build the embedder on the requested device. The consolidated build embeds
406    # 700k+ nodes in one pass; on Apple MPS the unified-memory watermark contends
407    # with the system file cache and OOMs on "other allocations", so
408    # `--embed-device cpu` is the reliable choice for the full corpus.
409    if opts.embed_device == "mps" and not _mps_available():
410        print("[x] --embed-device mps requested but MPS is not available")
411        return 1
412    if opts.embed_device == "cuda" and not _cuda_available():
413        print("[x] --embed-device cuda requested but CUDA is not available")
414        return 1
415    try:
416        embedder = make_embedder(device=opts.embed_device)
417    except Exception as exc:  # noqa: BLE001
418        print(f"[x] failed to build embedder on device {opts.embed_device!r}: {exc}")
419        return 1
420    print(f"  [embedder] {embedder!r}  (device={opts.embed_device})\n")
421
422    try:
423        # ------------------------------------------------------------------
424        # Phase 1: parse each strategy group into the shared SQLite graph.
425        # First group wipes (if opts.wipe); subsequent groups append.
426        # ------------------------------------------------------------------
427        n_groups = len(strategy_groups)
428        print(f"[1/4] parsing corpus → SQLite ({n_groups} strategy group(s)) …")
429        first = True
430        for strategy, sg_genres in sorted(strategy_groups.items()):
431            sg_exclude = derive_exclude(sg_genres)
432            print(f"  [{strategy}] {', '.join(sorted(sg_genres))}")
433            kg = DocKG(
434                corpus_root=CORPUS_ROOT,
435                db_path=sqlite_path,
436                lancedb_dir=lancedb_path,
437                exclude=sg_exclude,
438                embedder=embedder,
439                chunk_strategy=strategy,
440            )
441            kg.build_graph(wipe=first and opts.wipe, quiet=opts.quiet)
442            kg.close()
443            first = False
444
445        # ------------------------------------------------------------------
446        # Phase 2: embed all nodes in the combined graph.
447        # ------------------------------------------------------------------
448        print("[2/4] embedding nodes …")
449        kg_all = DocKG(
450            corpus_root=CORPUS_ROOT,
451            db_path=sqlite_path,
452            lancedb_dir=lancedb_path,
453            embedder=embedder,
454            # Served bundle is sqlite-vec (exact, ~10x smaller). Vectors land at
455            # <bundle>/.dockg/vectors.sqlite (derived from lancedb_dir's parent).
456            vector_backend="sqlite-vec",
457        )
458        # Resolve the effective device to pick the embedding path: CPU can fan
459        # out across processes safely; MPS/CUDA cannot (one shared allocator).
460        # `auto` prefers a GPU when available (MPS on Macs, CUDA elsewhere —
461        # e.g. RunPod), falling back to parallel CPU when no GPU is present.
462        #
463        # CAUTION: unlike `dockg build-index` (SemanticIndex.build(), which
464        # hard-caps its encode sub-batch at 128 — doc_kg PR #7 / kgmodule-utils
465        # 0.4.6), this streaming path (DocKG.build_embeddings ->
466        # precompute_embeddings -> _precompute_embeddings_jsonl_stream) has NO
467        # internal cap: --embed-batch-size is passed straight to
468        # model.encode() uncapped. It's safe today only because our own
469        # --embed-batch-size default (64) is small. Raising it for throughput
470        # while on MPS/CUDA for the full 700k+ node corpus reintroduces the
471        # batch x seq^2 unified-memory OOM PR #7 fixed elsewhere -- that fix
472        # does not reach this code path.
473        if opts.embed_device == "auto":
474            if _mps_available():
475                effective_device = "mps"
476            elif _cuda_available():
477                effective_device = "cuda"
478            else:
479                effective_device = "cpu"
480        else:
481            effective_device = opts.embed_device
482
483        if effective_device == "cpu" or opts.update:
484            # CPU (or any --update) → PARALLEL embedding via doc_kg's multi-process
485            # CorpusEmbedder (`.json` cache). This is the only path that supports
486            # incremental `only_missing` embedding. Pin every worker via
487            # KG_EMBED_DEVICE — even when the resolved device is MPS (--update):
488            # without the pin each worker auto-selects MPS and N workers stack
489            # N GPU allocations → OOM.
490            os.environ["KG_EMBED_DEVICE"] = "cpu"
491            # .jsonl streams vectors to disk as shards complete (CorpusEmbedder.
492            # embed_to_cache) instead of holding the whole corpus in RAM — peak memory
493            # is bounded by shard size, which is what kept the 689k-node build off swap.
494            cache_path = out_dir / "embeddings.jsonl"
495            mode = "incremental — embed only new/changed nodes" if opts.update else "full"
496            print(f"  [parallel] CPU multiprocessing ({mode})")
497            kg_all.build_embeddings(
498                out=cache_path,
499                n_workers=opts.n_workers,  # each worker loads its own model copy (~1.2 GB)
500                batch_size=opts.embed_batch_size,
501                only_missing=opts.update,
502                quiet=opts.quiet,
503            )
504        else:
505            # MPS/CUDA → single-process streaming to a `.jsonl` cache. The GPU
506            # allocator can't be shared across spawn workers without OOM, so
507            # parallelism is off here by design; streaming keeps GPU + host
508            # memory flat across the whole corpus (700k+ nodes).
509            cache_path = out_dir / "embeddings.jsonl"

555        # be several GB and must never ship in the bundle. Remove BOTH variants so a
556        # stale cache from a prior or killed run can't bloat the bundle (and the image
557        # COPY). .dockerignore guards the same at pack time as a belt-and-suspenders.
558        for _cache in ("embeddings.json", "embeddings.jsonl"):

562        # Phase 4: build (if needed) + bundle DiaryKG indices.
563        # ------------------------------------------------------------------

566            print("[x] diary build failed")

583            print("       gutenkg build-corpus --embed-device cpu --embed-batch-size 16")

473        # does not reach this code path.

486            # CorpusEmbedder (`.json` cache). This is the only path that supports
487            # incremental `only_missing` embedding. Pin every worker via
488            # KG_EMBED_DEVICE — even when the resolved device is MPS (--update):
489            # without the pin each worker auto-selects MPS and N workers stack
490            # N GPU allocations → OOM.
491            os.environ["KG_EMBED_DEVICE"] = "cpu"
492            # .jsonl streams vectors to disk as shards complete (CorpusEmbedder.
493            # embed_to_cache) instead of holding the whole corpus in RAM — peak memory
494            # is bounded by shard size, which is what kept the 689k-node build off swap.
495            cache_path = out_dir / "embeddings.jsonl"
496            mode = "incremental — embed only new/changed nodes" if opts.update else "full"
497            print(f"  [parallel] CPU multiprocessing ({mode})")
498            kg_all.build_embeddings(
499                out=cache_path,
500                n_workers=opts.n_workers,  # each worker loads its own model copy (~1.2 GB)
501                batch_size=opts.embed_batch_size,
502                only_missing=opts.update,
503                quiet=opts.quiet,
504            )
505        else:
506            # MPS/CUDA → single-process streaming to a `.jsonl` cache. The GPU
507            # allocator can't be shared across spawn workers without OOM, so
508            # parallelism is off here by design; streaming keeps GPU + host
509            # memory flat across the whole corpus (700k+ nodes).
510            cache_path = out_dir / "embeddings.jsonl"
511            print(f"  [stream] single-process on {effective_device}")
512            kg_all.build_embeddings(
513                out=cache_path,
514                n_workers=None,
515                batch_size=opts.embed_batch_size,
516                quiet=opts.quiet,
517            )
518
519        # ------------------------------------------------------------------
520        # Phase 3: build LanceDB index + SIMILAR_TO edges.
521        # ------------------------------------------------------------------
522        # On --update we UPSERT into the existing vector index (wipe=False) and skip
523        # SIMILAR_TO — the served handler is semantic-first and never traverses those
524        # edges, so recomputing 800k+ of them every update is pure waste.
525        index_wipe = opts.wipe and not opts.update
526        discover_similar = opts.discover_similar and not opts.update
527        print(
528            f"[3/4] building sqlite-vec index{' + SIMILAR_TO edges' if discover_similar else ' (upsert)' if opts.update else ''} …"
529        )
530        stats = kg_all.build_index_from_cache(
531            cache_path,
532            wipe=index_wipe,
533            discover_similar=discover_similar,
534            similar_k=opts.similar_k,
535            similar_max_degree=opts.similar_max_degree,
536            quiet=opts.quiet,
537        )
538
539        # Rebuild the FTS5 lexical index over the *full* consolidated graph so
540        # the handler's hybrid (dense + BM25) retrieval activates. build_graph()
541        # rebuilds it per strategy group, but we do it once more here as an
542        # explicit guard: it is the single artifact the lexical channel depends
543        # on, and an absent nodes_fts silently degrades retrieval to dense-only.
544        print("[3/4] building FTS5 lexical index (nodes_fts) over the full graph …")
545        n_fts = kg_all.store.rebuild_fts(quiet=opts.quiet)
546        print(f"  lexical index: {n_fts:,} chunks")
547
548        # Incremental adds only; drop index vectors for nodes that left the graph
549        # (removed/renamed books) so they can't return stale hits.
550        if opts.update:
551            print("[3/4] pruning orphan vectors (removed/renamed nodes) …")
552            kg_all.prune_index(quiet=opts.quiet)
553
554        kg_all.close()
555        # The embedding cache (.json / .jsonl) is a build-only intermediate — it can
556        # be several GB and must never ship in the bundle. Remove BOTH variants so a
557        # stale cache from a prior or killed run can't bloat the bundle (and the image
558        # COPY). .dockerignore guards the same at pack time as a belt-and-suspenders.
559        for _cache in ("embeddings.json", "embeddings.jsonl"):
560            (out_dir / _cache).unlink(missing_ok=True)
561
562        # ------------------------------------------------------------------
563        # Phase 4: build (if needed) + bundle DiaryKG indices.
564        # ------------------------------------------------------------------
565        print("[4/4] building + bundling DiaryKG indices …")
566        if ensure_diaries_built(dry_run=opts.dry_run, quiet=opts.quiet) != 0:
567            print("[x] diary build failed")
568            return 1
569        n_diaries = bundle_diaries(out_dir)
570        if n_diaries:
571            print(f"  copied {n_diaries} diary index(es) → bundles/{name}/diaries/")
572        else:
573            print("  (no .diarykg indices found under corpus/diaries/)")
574
575        print("[+] writing catalog.json (author/title from reference.md) …")
576        n_cat, n_auth = build_catalog(genres, out_dir)
577
578    except Exception as exc:  # noqa: BLE001
579        print(f"[x] build failed: {exc}")
580        msg = str(exc)
581        if "MPS backend out of memory" in msg:
582            print("[hint] Apple MPS OOM during embedding pass.")
583            print("[hint] Retry with CPU embeddings and a smaller embed batch:")
584            print("       gutenkg build-corpus --embed-device cpu --embed-batch-size 16")
585        return 1
586
587    elapsed = time.perf_counter() - t0
588    size_mb = _dir_size_mb(out_dir)
589
590    print()
591    print("=== build complete ===")
592    print(f"  bundle        : {name}")
593    print(f"  nodes         : {stats.total_nodes:,}")
594    print(f"  edges         : {stats.total_edges:,}")
595    if stats.similar_edges_added is not None:
596        print(f"  SIMILAR_TO    : {stats.similar_edges_added:,}")
597    print(f"  catalog       : {n_cat} books ({n_auth} with author)")
598    print(f"  diaries       : {n_diaries} index(es) bundled")
599    print(f"  index size    : {size_mb:,.1f} MB")
600    print(f"  elapsed       : {fmt_duration(elapsed)}")
601    print(f"  written to    : {out_dir}")
602    print()
603    return 0

Build one consolidated DocKG over the selected genres.

Genres are grouped by their effective chunk strategy, then each group is walked and parsed into the same graph.sqlite (first group wipes, the rest append). A single embedding pass and a single LanceDB index pass run over the combined node table. Finally, any DiaryKG indices found under corpus/diaries/ are copied verbatim into the bundle.

Parameters
  • genres: Genre names to include (already validated; empty == all).
  • opts: Build option flags.
Returns

0 on success, 1 on failure.
